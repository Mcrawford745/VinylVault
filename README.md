# VinylVault
Side project to learn/practice SpringBoot, Docker/Kubernetes, AWS, PostreSQL,Redis, Prometheus and Grafana etc

## Project Goals
- Build a REST API using Spring Boot
- Work with PostgreSQL
- Write automated tests
- Containerise the application with Docker
- Deploy to AWS
- Run services using Kubernetes

## Planned Features
- Collection Management
- Wishlist
- History
- Statistics

## Roadmap

### Phase 1:
- Basic Spring Boot REST API
- Create Record Model
- Implement CRUD operations
- Connect PostgreSQL
### Phase 2:
- Implement searching and filtering
- Expand Record information
### Phase 3:
- Add validation and error handling
- Write unit and integration tests
### Phase 4: 
- Containerise with Docker
### Phase 5:
- Generate Collection Stats
- Build Wishlist
- Build Listening History
### Phase 6:
- Add Auth and security
- Integrate external APIs
### Phase 7:
- Split into microservices
- Introduce Async messages
### Phase 8:
- Deploy to AWS
- Deploy with Kubernetes
- Add monitoring
